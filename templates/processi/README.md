# Processo Operativo ConsciusLabs

> Checklist step-by-step per gestire un cliente dall'inizio alla fine

---

## 🎯 FASE 1: ACQUISIZIONE CLIENTE

### Step 1.1: Ricerca Target (30 min)
- [ ] Definisci nicchia target (es: coach, imprenditori, creator)
- [ ] Crea lista di 20-30 potenziali clienti
- [ ] Verifica che producano contenuti regolarmente
- [ ] Controlla che abbiano presenza multi-piattaforma

**Dove cercare:**
- LinkedIn (hashtag #contentcreator #imprenditore)
- YouTube (canali con 1K-50K subscriber)
- Instagram (creator con buon engagement)
- Podcast italiani (Spotify, Apple Podcasts)

---

### Step 1.2: Cold Outreach (15 min per email)
- [ ] Personalizza email (usa template base)
- [ ] Menciona contenuto specifico che hai visto
- [ ] Spiega value proposition chiara
- [ ] Chiudi con call to action specifica
- [ ] Invia e segna su spreadsheet tracking

**Tracking Spreadsheet (colonne):**
```
| Data Invio | Nome | Email | Piattaforma | Stato | Data Follow-up | Note |
```

---

### Step 1.3: Follow-up (3-4 giorni dopo)
- [ ] Se non rispondono: invia follow-up email
- [ ] Se rispondono positivamente: proponi call
- [ ] Se rispondono negativamente: chiedi perché (feedback)

---

## 🤝 FASE 2: ONBOARDING

### Step 2.1: Call Conoscitiva (15 min)
**Prima della call:**
- [ ] Prepara domande standard
- [ ] Guarda 2-3 contenuti recenti del cliente
- [ ] Prendi nota di tono di voce e stile

**Durante la call:**
- [ ] Presentati (30 secondi)
- [ ] Chiedi: che tipo di contenuto produci?
- [ ] Chiedi: quali piattaforme usi attivamente?
- [ ] Chiedi: qual è il tuo pubblico target?
- [ ] Chiedi: cosa ti blocca nel creare più contenuti?
- [ ] Spiega processo e tempistiche
- [ ] Chiedi: vuoi provare il test gratuito?

**Dopo la call:**
- [ ] Invia email riassuntiva
- [ ] Allega link per caricare contenuto
- [ ] Conferma data consegna

---

### Step 2.2: Ricezione Contenuto
- [ ] Verifica che il link funzioni
- [ ] Scarica il contenuto originale
- [ ] Verifica qualità audio/video
- [ ] Se qualità scarsa: avvisa cliente
- [ ] Se qualità ok: conferma ricezione

---

## 🔄 FASE 3: PRODUZIONE

### Step 3.1: Analisi Contenuto (30 min)
- [ ] Guarda/ascolta tutto il contenuto
- [ ] Identifica momenti chiave (hook, insight, quote)
- [ ] Prendi note su timestamp importanti
- [ ] Definisci angle per ogni piattaforma

---

### Step 3.2: Creazione Asset

**Video Clips (se richiesto):**
- [ ] Seleziona 5-10 momenti migliori
- [ ] Taglia clip 15-60 secondi
- [ ] Aggiungi sottotitoli burn-in
- [ ] Esporta in 1080x1920 (9:16)
- [ ] Verifica qualità finale

**Testi Social:**
- [ ] Scrivi 3-5 post LinkedIn
- [ ] Scrivi 1 thread X (5-7 tweet)
- [ ] Scrivi 2-3 caption Instagram
- [ ] Ottimizza hashtag per piattaforma
- [ ] Verifica lunghezza (LinkedIn max 3000 char)

**Grafiche (se richiesto):**
- [ ] Crea 1-2 caroselli (5-10 slide)
- [ ] Crea 3-5 quote cards
- [ ] Usa brand colors del cliente
- [ ] Esporta PNG alta risoluzione

**Newsletter (se richiesto):**
- [ ] Scrivi oggetto email (hook)
- [ ] Scrivi body (3-5 paragrafi)
- [ ] Aggiungi CTA chiara
- [ ] Crea versione HTML e TXT

---

### Step 3.3: Controllo Qualità
- [ ] Rileggi tutti i testi (no typo)
- [ ] Verifica coerenza brand voice
- [ ] Controlla che i link funzionino
- [ ] Prova video (audio ok? sottotitoli leggibili?)
- [ ] Verifica dimensioni file

---

## 📦 FASE 4: CONSEGNA

### Step 4.1: Preparazione Cartella
- [ ] Crea cartella Google Drive con nomenclatura standard:
  `ConsciusLabs_[Cliente]_[Progetto]_[Data]`
- [ ] Organizza file per sottocartelle (Video, Testi, Grafiche, etc.)
- [ ] Crea README.pdf con istruzioni
- [ ] Verifica permessi condivisione ("Anyone with link can view")

---

### Step 4.2: Invio
- [ ] Usa template email "CONSEGNA LAVORO"
- [ ] Allega link Drive
- [ ] Spiega cosa trova nella cartella
- [ ] Ricorda: 24h per modifiche
- [ ] Chiedi feedback

---

### Step 4.3: Post-Consegna

**Dopo 24 ore:**
- [ ] Se nessuna richiesta modifiche: follow-up "Tutto ok?"
- [ ] Se richieste modifiche: esegui e riconsegna

**Dopo 3-4 giorni:**
- [ ] Chiedi feedback sul risultato
- [ ] Chiedi se interessato a piano mensile
- [ ] Se sì: invia proposta piano
- [ ] Se no: chiedi perché (obiezioni)

---

## 💰 FASE 5: CONVERSIONE E RETENTION

### Step 5.1: Attivazione Cliente Pagante
- [ ] Conferma piano scelto (Base/Standard/Pro)
- [ ] Chiedi dati fatturazione
- [ ] Invia IBAN per bonifico
- [ ] Attendi pagamento
- [ ] Conferma ricezione pagamento

---

### Step 5.2: Gestione Mensile Cliente

**Inizio mese:**
- [ ] Invia email "Piano contenuti [Mese] — prepariamo il prossimo batch?"
- [ ] Attendi contenuti da repurpare
- [ ] Se non arrivano: follow-up dopo 3 giorni

**Durante il mese:**
- [ ] Produci contenuti entro 48h dalla ricezione
- [ ] Consegni secondo checklist Fase 4
- [ ] Traccia performance su spreadsheet

**Fine mese:**
- [ ] Invia report performance (se disponibili)
- [ ] Chiedi feedback generale
- [ ] Proponi rinnovo per mese successivo
- [ ] Se rinnova: continua
- [ ] Se non rinnova: chiedi perché (exit interview)

## ⚠️ ERRORI COMUNI DA EVITARE

1. **Non personalizzare outreach** → Clienti non rispondono
2. **Non verificare qualità contenuto** → Problemi in produzione
3. **Non rispettare deadline** → Perdi fiducia
4. **Non chiedere feedback** → Non migliori mai
5. **Non fare follow-up** → Perdi vendite
6. **Non tracciare performance** → Non sai cosa funziona

**Ogni mese, traccia:**
- [ ] Email inviate
- [ ] Risposte ricevute
- [ ] Call completate
- [ ] Test gratuiti fatti
- [ ] Clienti convertiti
- [ ] Fatturato totale
- [ ] Client retention rate

**Obiettivi M1:**
- 50 email inviate
- 10 risposte (20%)
- 5 call fatte
- 3 test gratuiti
- 1 cliente pagante

---

## 🆘 EMERGENZE: COSA FARE SE...

**Cliente insoddisfatto:**
- Chiedi specificamente cosa non va
- Offri revisione gratuita
- Se non risolvibile: offri rimborso parziale

**Contenuto qualità scarsa:**
- Avvisa cliente prima di iniziare
- Spiega limitazioni
- Proponi di usare contenuto diverso

**Ritardo consegna:**
- Avvisa cliente prima della deadline
- Spiega motivo
- Offri bonus (contenuto extra gratis)

**Cliente non paga:**
- Fattura a 30 giorni
- Sollecito a 45 giorni
- Stop servizio a 60 giorni
